## 开源项目 (Open Source)

| 项目 | 简介 | 标签 |
| --- | --- | --- |
| [A2UI](https://github.com/a2ui-project/a2ui) | 开源生成式 UI 框架（Agent-to-User Interface），Agent 流式输出结构化布局数据，应用端以 React、Angular、Lit、Flutter、SwiftUI、Jetpack Compose 等原生组件安全渲染 | `生成式UI` `Agent` `跨端渲染` |
| [moejs](https://github.com/MoeForge/moejs) | 纯 Go 实现的高性能 JavaScript 运行时，专为在 Go 程序中快速运行大量小型插件沙箱而设计，支持 ES 模块、async/await 等现代 JS 特性 | `Go` `JavaScript运行时` `插件沙箱` |
| [Mainline](https://github.com/mainline-org/mainline) | 面向 Coding Agent 的 Git 原生记忆层，将开发意图、工程决策、权衡取舍、约束与已放弃路线随代码一起存入 Git 仓库 | `Agent记忆` `Git` `CodingAgent` |
| [Astryx](https://github.com/meta/astryx) | Meta 开源的可定制设计系统，基于 React 与 StyleX，提供无障碍 UI 组件、主题、暗色模式及面向开发者和 AI Agent 的 CLI 工具 | `设计系统` `React` `Agent友好` |
