## 开源项目 (Open Source)

| 项目 | 简介 | 标签 |
| --- | --- | --- |
| [A2UI](https://github.com/a2ui-project/a2ui) | 开源生成式 UI 框架（Agent-to-User Interface），Agent 流式输出结构化布局数据，应用端以 React、Angular、Lit、Flutter、SwiftUI、Jetpack Compose 等原生组件安全渲染；[官网](https://a2ui.org/) | `生成式UI` `Agent` `跨端渲染` |
| [moejs](https://github.com/MoeForge/moejs) | 纯 Go 实现的高性能 JavaScript 运行时，专为在 Go 程序中快速运行大量小型插件沙箱而设计，支持 ES 模块、async/await 等现代 JS 特性 | `Go` `JavaScript运行时` `插件沙箱` |
| [Mainline](https://github.com/mainline-org/mainline) | 面向 Coding Agent 的 Git 原生记忆层，将开发意图、工程决策、权衡取舍、约束与已放弃路线随代码一起存入 Git 仓库 | `Agent记忆` `Git` `CodingAgent` |
| [Astryx](https://github.com/meta/astryx) | Meta 开源的可定制设计系统，基于 React 与 StyleX，提供无障碍 UI 组件、主题、暗色模式及面向开发者和 AI Agent 的 CLI 工具 | `设计系统` `React` `Agent友好` |
| [Obscura](https://www.obscura.sh/) | 面向 AI Agent 和网页抓取的开源无头浏览器引擎，提供隔离的浏览器会话，支持 Playwright 和 Chrome DevTools Protocol，可自托管或使用托管服务；[开源仓库](https://github.com/h4ckf0r0day/obscura) | `Agent` `无头浏览器` `网页抓取` |
| [Native Shell](https://nsh.dev/) | Rust 跨平台原生 UI 框架，一套应用面向移动端、桌面端和 Web，使用各平台的原生界面与交互；[开源仓库](https://github.com/longbridge/nsh) | `Rust` `跨平台` `原生UI` |
| [MyGo](https://mygo.egoist.dev/) | Go 桌面应用框架，支持以 Go 编写 GPU 绘制界面，或通过系统 WebView 使用 Web 前端；[开源仓库](https://github.com/egoist/mygo) | `Go` `桌面应用` `跨平台` |
| [Asuka](https://asuka.egoist.dev/) | Go 跨平台应用框架，使用各平台原生控件构建移动端、桌面端和 Web 界面，支持响应式信号和热重载；[开源仓库](https://github.com/egoist/asuka) | `Go` `跨平台` `原生UI` |
| [NSGo](https://nsgo.dev/) | 跨平台原生 UI 框架，支持使用 Go 或 TSX 开发移动端、桌面端和 Web 应用，并实验性支持 Go 小程序；[开源仓库](https://github.com/nsgo-dev/nsgo) | `Go` `TSX` `跨平台` `原生UI` |
| [Rivet](https://rivet.dev/) | 面向 AI Agent 的开源运行与编排平台，提供持久执行、状态持久化及不受信任代码执行能力，支持自托管；[开源仓库](https://github.com/rivet-dev/rivet) | `Agent` `持久执行` `自托管` |
| [Nango](https://github.com/NangoHQ/nango) | 面向 AI Agent 的集成平台，提供预构建 API 工具、托管身份认证、API 代理及数据同步，支持使用 TypeScript 自定义集成；[官网](https://nango.dev/) | `Agent` `API集成` `身份认证` |
| [magpie](https://github.com/yetone/magpie) | 面向 Coding Agent 的模型管理工具，通过本地网关统一配置模型和服务商，支持账号与模型切换及额度耗尽时的故障转移；[官网](https://usemagpie.ai/) | `CodingAgent` `模型网关` `多模型` |

| [Composio](https://github.com/ComposioHQ/composio) | 面向 AI Agent 的工具集成平台 SDK，连接众多应用，提供用户会话、身份认证、触发器及沙箱，支持 Python、TypeScript 和主流 Agent 框架；[官网](https://composio.dev/) | `Agent` `工具集成` `SDK` |
